# WellTrack

A Python-based personal wellbeing check-in application designed to record and organize basic daily wellbeing indicators.

## 📌 Project Overview

WellTrack is an early-stage personal wellbeing project focused on helping users reflect on their daily experiences through structured self-reporting.

The current version provides a command-line check-in where users can enter ratings for mood, stress, anxiety, energy levels, and sleep duration. Input validation is included to ensure that ratings remain within the expected range.

This project will gradually evolve into a larger wellbeing platform incorporating data analysis, visualization, personalized insights, and eventually machine learning and optional physiological data.

## ✨ Current Features

- Daily wellbeing check-in
- Mood rating (1–10)
- Stress rating (1–10)
- Anxiety rating (1–10)
- Energy rating (1–10)
- Sleep duration tracking
- Input validation
- Repeated prompting for invalid ratings
- Modular Python functions
- Structured program flow

## 🔮 Planned Development

The project is being developed incrementally. Planned improvements include:

1. Reusable input and validation functions
2. Persistent data storage
3. Daily and weekly wellbeing trends
4. Data visualization
5. Personalized pattern analysis
6. Adaptive reminders
7. Sleep and activity data integration
8. Optional wearable/physiological data integration
9. Machine learning for personal pattern detection
10. A conversational wellbeing companion with appropriate safety boundaries

> **Note:** WellTrack is intended as a personal wellbeing and self-reflection tool. It is not designed to diagnose, treat, or replace professional medical or psychological care.
